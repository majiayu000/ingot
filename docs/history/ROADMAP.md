# 当前路线（2026-10-13）

> **历史记录（2026-10-13 快照）**：本文未随后续实现更新。MTP、前缀缓存、大块预填充等已实现，当前状态见 [README.md](../../README.md)。

新阶段按 [性能能力补全 Spec](OPTIMIZATION_SPEC.md) 推进：覆盖主要优化、同机对标和完整请求质量/速度验收。以下条目记录已完成的历史阶段，不代表性能目标已达成。

用户已授权实施 [完整架构](../ARCHITECTURE.md)。以 [实际验证](NATIVE_VALIDATION.md) 为准。

1. **Qwen 主线：已实现。** 12 种格式、分词、48 层前向、超连接、GDN、QSA、PLE、
   会话状态及完整 greedy 文本生成。本轮新增 69 个独立 reference 位置全部 top-1 对齐，
   2112-token 状态/全词表回归通过；独立长上下文语言质量仍需扩大。
2. **有限内存：已实现主要路径。** 固定槽位 LRU、I/O 与计算重叠、8-token 分组预填充。
   已验证指定输入下与常驻/逐 token 路径一致、8 GiB 预算及完整 8192-token 状态执行。继续区分暖文件缓存
   与可证明的冷 SSD 读取，不用 pread 字节数冒充物理读取量。
3. **性能：已完成第三轮实现与三组交替对照。** 四行 SIMD 投影、量化块信息复用、
   GLM 分组投影/专家预填充、稀疏注意力跳过。第三轮同条件下，Qwen 8 / 40 GiB 的
   decode 吞吐分别提高 12.3% / 10.4%，GLM 32 GiB 提高 18.8%；平均请求时间分别
   缩短 13.0% / 16.3% / 15.2%。全部输出和 EOS 一致，原始样本和方差均保留。
   系统缓存/后台负载没有隔离，各轮条件不同，不混算累计倍数。
   进一步优化以真实 profile 和独立质量对照为依据；MTP、随机采样尚未实现。
4. **GLM 5.3 Flash：已实现并通过当前短请求验收。** 固定版本 ggml-org Q2_K_S
   （约 110 GB）两分片已完成 SHA-256 校验。161 个位置的首选 token、140 个生成 token
   和 EOS 与独立参考一致；本轮新增 66 个独立 reference 位置全部 top-1 对齐，
   2112-token 状态/全词表回归通过，11/16/24 GiB 预算及 1/8-token 取消检查通过。
   10 月 12 日的 16 GiB 完整请求峰值为 15.56 GiB；本轮 32 GiB 成绩见第 3 项。
   独立长上下文语言质量和可控冷读性能仍待验证。
